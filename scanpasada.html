ScanPasada

Kotlin Jetpack Compose Supabase PostgreSQL

ScanPasada is an Android app that modernizes and manages the informal jeepney queueing at Philippine terminals. Operators can create and manage queues for specific routes, drivers know exactly when it is their turn in the queue, and passengers can track the jeepney location and queueing status in real time. The app uses QR code scanning for quick identification and pushes live updates so everyone stays in sync. It is built with Kotlin and uses Supabase as the backend for storing data and streaming real-time changes to all users. Features in development include scheduled queues, passenger counting, driver ratings, and a web dashboard for terminal monitoring.

The problem it solves

Jeepney terminals in the Philippines still run on an informal queue. Drivers scramble for position without knowing when their turn actually is, passengers cannot tell which jeepney leaves next or where it currently is, and operators have no way of seeing what is happening at their own terminal. The result is a daily routine that feels chaotic, wasteful, and unfair to everyone involved.

ScanPasada modernizes this by managing the queue digitally. Drivers know exactly when it is their turn, passengers can track the jeepney location and queueing status in real time, and operators can finally manage and monitor their terminal straight from their phone.
